# [SFC] 파이널 판타지4 한글패치

슈퍼패미콤 **파이널 판타지4** 한글패치입니다. 슈퍼패미콤 실기에서 구동하는 것을 목표로 작업했습니다.

- 블로그 소개글: https://dwyn.tistory.com/
- 최신 버전 다운로드: [Releases](../../releases/latest)
- 버그 제보: [Issues → 버그 제보](../../issues/new/choose)
- 후원: https://litt.ly/dwyn

## 주요 작업 사항

1. 슈퍼패미콤 실기에서 구동되는 것을 목표로 한 한글패치입니다.
2. 픽셀 리마의 번역을 참조했습니다.
3. HP, MP, LV를 제외한 모든 텍스트를 번역하려고 했습니다.
4. 기존 패치들처럼 주인공 이름은 자동으로 세팅되고 넘어가도록 했습니다.

**→ 그간 작업의 노하우로 이것저것 챙기긴 했지만, 실기 검수는 아직 하지 못했습니다.**

## 추가 기능

설정 메뉴 2쪽(설정 1쪽 맨 아래에서 아래 버튼)에서 바꿀 수 있습니다.

1. 경험치획득 > 기본, ×2, ×4, ×8
2. 길획득 > 기본, ×2, ×4, ×8
3. 인카운터회피 > 꺼짐, 항상, R버튼
   - "항상"으로 설정하면 전투가 발생하지 않습니다.
   - "R버튼"으로 설정하면 필드에서 R 버튼을 누르고 있는 동안 전투가 발생하지 않습니다. 이때는 R 버튼으로 맨 앞 캐릭터를 바꾸는 기능이 꺼집니다.
4. 대시 > 꺼짐, 항상, B버튼
   - "항상"으로 설정하면 마을과 필드에서 걷는 속도가 2배가 됩니다. (탈것과 이벤트 이동은 그대로입니다.)
   - "B버튼"으로 설정하면 B 버튼을 누르고 있는 동안만 빨라집니다.

**버튼 모드 제한**: 컨트롤러 설정에서 B 버튼에 원래 기능(취소)이 아닌 다른 기능을 지정하면 대시의 "B버튼" 모드를 쓸 수 없습니다. (R 버튼은 버튼 설정에서 바꿀 수 없어서 인카운터회피의 "R버튼" 모드는 항상 쓸 수 있습니다.)

- 설정에서 대시의 맨 오른쪽 칸(B버튼)으로 옮기려 하면 경고음이 나고 이동하지 않습니다. "항상"은 이 상태에서도 그대로 고를 수 있습니다.
- 이미 "B버튼"이었다면 버튼 설정을 바꾸고 설정을 닫을 때, 그리고 설정 2쪽에 들어갈 때 자동으로 "꺼짐"이 됩니다.
- 필드에서도 매번 다시 확인해서, 충돌 상태면 "B버튼" 모드가 작동하지 않습니다.

## 적용 방법

1. [Releases](../../releases/latest)에서 패치 파일을 받습니다.
2. 직접 가지고 계신 원본 ROM에 패치를 적용합니다.
   - 웹에서 적용: [ROM Patcher JS](https://www.marcrobledo.com/RomPatcher.js/)
   - PC 프로그램: Delta Patcher, Floating IPS 등
3. 패치된 ROM을 에뮬레이터나 플래시카트로 실행합니다.

### 체크섬 확인

패치는 **헤더 없는 일본판 원본 ROM (Rev 1)**(1,048,576바이트)에 적용해야 합니다.

| 구분 | CRC32 | MD5 | SHA1 |
|---|---|---|---|
| 원본 ROM (일본판 Rev 1) | `CAA15E97` | `A2959AD8C1FF5F2719264AB4C7E40464` | `EAC14578B3465FFCE874119005F9B244E8565A79` |
| 패치 후 (v1.3, 2,097,152바이트) | `9054417D` | `DB3BE8319CCE71E9D0898110489D65EE` | `78FEBC92B17F11B8EF46E226DDCAF321E2E5E561` |

- ROM Patcher JS에 ROM 파일을 넣으면 CRC32, MD5, SHA1이 바로 표시됩니다.
- 크기가 1,049,088바이트인 ROM은 512바이트 헤더가 붙은 파일이니, 헤더를 제거한 뒤 적용해 주세요.
- 일본판 초판(Rev 0) ROM에는 적용되지 않습니다. 체크섬이 위 표와 같은지 확인해 주세요.

> 이 저장소에는 패치 파일만 있습니다. ROM 파일이나 패치를 적용한 ROM은 배포하지 않으며, 요청에도 응하지 않습니다.
